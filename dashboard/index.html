Token Radar

Every protocol the snapshot tracks, ranked by what its token launch would be worth — and how to farm each one before it happens.

How value is scored

Implied value = TVL × peer multiple × growth × age × chains. The peer multiple is the median market-cap/TVL ratio of the tokenized protocols in the same category, computed from this snapshot — never a hardcoded list of names. Protocols whose token already trades show their actual market cap (TOKEN LIVE); where the snapshot reports no market cap for a live entry, the peer-modeled value is shown instead and flagged. Wrapped, staked or bridged products of a traded token are WRAPPED, ranked last at 1% of peer value — a wrapper cannot launch. The page shows the top 735 rows; the full 758-row board is in board.json.
